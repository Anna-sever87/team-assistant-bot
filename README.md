# Командный Telegram-бот на пайплайнах Haystack

Бот работает в рабочем чате: запоминает все сообщения вместе с авторами, подводит итог обсуждения, отвечает на обращения по контексту переписки и ищет по истории чата по смыслу.

## Что умеет

- Запоминает каждое сообщение чата (автор, время, текст) в векторной базе Pinecone.
- `/start_listening` начинает слушать обсуждение, `/stop_listening` заканчивает и присылает итог: тему, ключевые тезисы, мнение бота по спору или принятое решение, рекомендации.
- Если обратиться к боту через `@имя_бота` или ответить на его сообщение, он отвечает с учётом последних сообщений и найденных по смыслу сообщений из истории.
- `/find текст` ищет в истории чата сообщения по смыслу.
- `/chat_id` показывает ID чата.
- Доступ в личных сообщениях ограничен списком `ALLOWED_USER_IDS`, группы можно ограничить списком `ALLOWED_CHAT_IDS`.

## Как устроено

Три пайплайна Haystack:

1. **Индексация**: эмбеддер (OpenAI) → запись в Pinecone.
2. **Поиск**: эмбеддер запроса → поиск в Pinecone с фильтром по чату.
3. **Саммаризация и ответ**: эмбеддер запроса → поиск в Pinecone → сборка промпта → языковая модель (OpenAI).

Все сообщения лежат в одном индексе, пространство имён `team-chat`. В метаданных хранятся ID чата, автор, время и тип записи, поэтому поиск идёт только по истории нужного чата.

## Файлы

| Файл | Назначение |
|---|---|
| `bot.py` | Telegram-бот: команды, обработка сообщений |
| `pipelines.py` | Три пайплайна Haystack и менеджер для работы с ними |
| `components.py` | Свои компоненты Haystack: запись в Pinecone, поиск, сборка промпта |
| `vector_store.py` | Работа с Pinecone |
| `chat_context.py` | Последние сообщения чата и сессии прослушивания |
| `prompts.py` | Системный промпт и шаблоны |
| `config.py` | Настройки из `.env` |
| `results/test_log.txt` | Результаты тестирования |

## Установка и запуск

```
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните ключи Pinecone и OpenAI, токен бота из @BotFather и свой Telegram ID. Затем:

```
python bot.py
```

## Настройка Telegram

Чтобы бот видел все сообщения группы, в @BotFather отключите privacy mode: `/setprivacy`, выберите бота, нажмите `Disable`. После этого удалите бота из группы и добавьте снова.

## Примечания

- Для Pinecone использованы собственные компоненты (запись и поиск) вместо готовой интеграции Haystack, чтобы управлять метаданными, фильтрами и пространствами имён.
- Для сборки промпта использован собственный компонент вместо `ChatPromptBuilder`.
- Туториал по Extractive QA в проект не включён.
- Файл `.env` с ключами в репозиторий не попадает (он в `.gitignore`).
